# Zipper Bot

Telegram-бот для сжатия файлов в ZIP-архивы, распаковки ZIP-файлов и анализа их содержимого.

## Возможности

- создание ZIP-архива из нескольких файлов;
- распаковка ZIP-файла;
- просмотр списка и размеров файлов в архиве;
- защита от ZIP-bomb и небезопасных путей;
- ограничение размера и количества файлов.

## Установка

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и укажите токен бота, полученный у [BotFather](https://t.me/BotFather):

```text
BOT_TOKEN=your_telegram_bot_token
```

Перед запуском через PowerShell загрузите переменную окружения:

```powershell
$env:BOT_TOKEN = "ваш_токен"
python bot.py
```

## Ограничения

- не более 100 файлов;
- до 50 МБ на отдельный файл;
- до 100 МБ суммарного распакованного объема;
- архивы с паролем не поддерживаются.
